# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
The kernel is the core part of the OS that talks to the hardware. Programs ask it when they need memory, CPU time, files or the network, and it shares those out between everything that's running.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
Not really. WSL 2 runs a real Linux kernel, but inside a lightweight VM that Windows manages. It depends on Windows to run, uses the same hardware, and can even access Windows files through `/mnt/c`, so it's more like Linux built into Windows than two separate systems.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
The terminal is the window I type into, e.g. Windows Terminal. The shell is the program inside it that actually reads and runs my commands, e.g. bash.
